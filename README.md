# agency-data-commons

Shared Python packages for the Agency Data Trust Series: the canonical schema (`agency_schema`),
the synthetic agency data generator (`synth_agency_data`), and the Jev (TypeSafe) client
(`jev_client`). agency-intake-kit, bob-resolve, and plan-diff install one copy from here.

Synthetic data only. Work in progress: the packages arrive in PR C0a.
